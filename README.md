# TMSpath Pipeline

TMSpath is a Python pipeline for the preprocessing, analysis, visualization, and feature extraction of transcranial magnetic stimulation combined with electroencephalography data, TMS-EEG, and conventional EEG recordings.

## Purpose of the repository

This repository provides a structured and reproducible framework for processing:

- TMS-EEG recordings;
- TMS-evoked potentials, TEPs;
- resting-state EEG;
- continuous EEG recordings.

The pipeline includes procedures for:

- loading EEG data from different acquisition formats;
- detecting TMS events and creating TMS-locked epochs;
- removing the immediate TMS pulse artifact;
- filtering EEG signals;
- identifying and rejecting bad trials;
- detecting and managing bad channels;
- correcting capacitive and post-TMS artifacts;
- applying windowed and non-windowed detrending;
- fitting polynomial and physiologically inspired artifact models;
- performing independent component analysis, ICA;
- automatically classifying artifactual ICA components;
- manually inspecting ICA components;
- interpolating bad channels;
- applying average re-referencing;
- estimating power spectral density;
- separating aperiodic and oscillatory spectral components;
- extracting standard TMS-evoked features;
- estimating TEP energy and absolute integral;
- computing the Perturbational Complexity Index based on state transitions, PCIst;
- estimating the natural frequency of TMS-evoked responses;
- characterizing temporal TEP fingerprints;
- generating scalp topographies, butterfly plots, ERSP maps, PSD plots, and summary figures;
- saving processing parameters, intermediate objects, results, random seeds, and reproducibility information.

TMSpath is intended to support reproducible scientific research in neurophysiology, epilepsy, cortical excitability, brain stimulation, and EEG signal processing.

The pipeline was developed within the **TMSpath clinical research project**, which investigates transcranial magnetic stimulation as a tool for characterizing pathophysiological mechanisms in genetic epilepsies.

The clinical study is registered on ClinicalTrials.gov as:

The study uses TMS-EMG and TMS-EEG to investigate cortical excitability and reactivity in genetic epilepsies.

The protocol includes the assessment of:

- cortical reactivity;
- neurophysiological effects associated with genetic mutations;
- potential diagnostic and prognostic biomarkers;
- potential markers for monitoring precision treatments.

## TMS-EEG artifact correction

TMS-EEG recordings can be affected by physiological and non-physiological artifacts, including:

- the immediate electromagnetic artifact generated by the TMS pulse;
- amplifier saturation and recovery;
- electrode polarization;
- capacitive charging and discharging;
- cranial and facial muscle activity;
- eye movements and blinks;
- auditory and somatosensory responses;
- power-line interference;
- slow post-stimulus drifts.

TMSpath includes a dedicated framework for correcting severe capacitive artifacts.

The artifact can be divided into temporally distinct portions and modeled using windowed detrending. Separate models can be applied to the pre-offset, artifact-rise, and post-offset decay periods.

The implemented approaches include:

- polynomial detrending;
- constrained polynomial fitting;
- Lagrange polynomial fitting;
- exponential models;
- bi-exponential models;
- alpha-function models;
- power-law models;
- spline-based models;
- non-windowed fitting procedures.

This framework is intended for cases in which large nonlinear capacitive artifacts cannot be sufficiently isolated using ICA alone.

## EEG and resting-state processing

The repository also supports EEG recordings without TMS stimulation.

The EEG and resting-state workflow includes:

- continuous-data preprocessing;
- filtering;
- annotation and exclusion of bad temporal segments;
- bad-channel detection;
- ICA decomposition;
- automatic or manual component rejection;
- bad-channel interpolation;
- average re-referencing;
- power spectral density estimation;
- channel-wise spectral analysis;
- aperiodic and oscillatory component analysis;
- extraction of resting-state features;
- generation of control and null distributions;
- comparison between resting-state and TMS-evoked measures.

## Reproducibility

TMSpath stores the main parameters and outputs of each analysis in recording-specific JSON files.

The recorded metadata can include:

- subject identifier;
- recording type;
- stimulation hemisphere;
- pipeline version;
- filtering and epoching parameters;
- rejected trials;
- bad channels;
- detrending settings;
- fitted artifact models;
- ICA settings;
- selected and excluded ICA components;
- interpolation settings;
- extracted features;
- random seeds;
- software dependencies;
- input and output paths;
- data and file hashes.

Intermediate and final MNE objects can be serialized as PKL files.

The repository can also include:

- a dependency log describing the software environment;
- a version-locked list of installed Python packages;
- version information for the TMSpath pipeline;
- Git commit information associated with the analysis.

## Intended use

TMSpath is intended for scientific research involving TMS-EEG and EEG data.

The pipeline does not replace:

- appropriate experimental design;
- TMS-compatible EEG hardware;
- correct electrode preparation;
- monitoring of electrode impedance;
- online artifact prevention;
- visual inspection of the data;
- expert neurophysiological interpretation.

Offline preprocessing cannot fully reconstruct neural information that was irreversibly lost because of amplifier saturation, clipping, excessive noise, or inadequate acquisition settings.

TMSpath is not a certified medical device and must not be used as the sole basis for clinical diagnosis, prognosis, or treatment decisions.
